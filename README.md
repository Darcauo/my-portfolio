# Portfolio

A responsive, single-page portfolio template built with plain HTML, CSS, and JavaScript.

## Files

- `index.html` — portfolio sections and blank content slots
- `styles.css` — responsive layout, colors, and visual styling
- `script.js` — navigation menu behavior and current year
- `404.html` — styled not-found page
- `favicon.svg` — simple geometric brand mark

## Preview

Open `index.html` in a browser, or start a local server from this folder:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.
